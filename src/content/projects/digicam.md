Fully functioning digital camera with UI and photo library built on an STM32. Images are captured with an OV2640 and stored on an SD card.

## Highlights

- Image capture via OV2640 camera sensor
- Shared SPI bus between camera and display
- FatFS on SD card for file storing/retrieval
